# hermes-config

Memoria y skills del agente Hermes que corre en el VPS de DólarBolivia.

- `memories/MEMORY.md` — notas internas del agente (entorno, convenciones, lecciones).
- `memories/USER.md` — perfil del usuario (preferencias, estilo de trabajo).
- `skills/` — skills en texto (SKILL.md, references, scripts). Se excluyen imágenes, fuentes y
  binarios para no inflar el repo.

Repo privado: puede contener rutas, IDs de canales y detalles del servidor.

## Cómo se actualiza

Se copian los archivos desde `~/.hermes/` y se hace commit. No lo edites acá esperando que baje
al servidor: la fuente de verdad es el VPS.
